## [0.1.0] - 2026-11-27

### Added

- Fourteen weighted repository health checks with actionable recommendations.
- Console, JSON, Markdown, standalone HTML, and local SVG badge output.
- `fix` command for non-destructive community-health file scaffolding.
- Minimum-score CI enforcement and a reusable GitHub Action.
- Zero-dependency Python 3.9+ package and comprehensive unit tests.
